# 🪕 Cahier de Chant Ukulélé

Ce projet contient votre recueil de chansons pour ukulélé.

## 📁 Organisation des fichiers
- `cahier_ukulele.html` : **Version maîtresse imprimable** avec rendu graphique des diagrammes d'accords SVG, alignement typographique précis et sauts de page A4 automatiques (1 page = 1 chanson).
- `cahier_ukulele.md` : Version Markdown complète.
- `accords_base.md` : Dictionnaire de référence des accords et doigtés.
- `chansons/` : Dossier contenant les fiches individuelles de chaque chanson.

## 🖨️ Comment imprimer ou exporter en PDF ?
1. Ouvrez `cahier_ukulele.html` dans Safari, Chrome ou votre navigateur habituel.
2. Cliquez sur le bouton **"🖨️ Imprimer / Exporter en PDF"** (ou `Cmd + P`).
3. Choisissez **Enregistrer au format PDF** ou imprimez directement. Les marges et sauts de page sont automatiquement calibrés.
